## 숙박비 저장 정책

- 기존 보조 DB hotel-web-prices.sqlite에 hotel_price_reserve 테이블 추가. 원본 관광지/회원/일정 MariaDB 테이블은 변경하지 않음.
- 일정 생성 때 숙소별 가격 조회 실패를 기록. 동일 생성 작업의 같은 숙소는 한 번만 집계.
- 5회 연속 실패하면 이전에 검증된 가격을 보완 요금으로 사용. 유효한 이전 가격이 없으면 임의의 요금을 생성하지 않음.
- 이후 정상 조회된 새 1박 최저가가 최우선이며 저장 요금도 새 값으로 교체. 다시 실패하면 저장값 사용.
- 단순 일정 조회는 실패 횟수를 늘리거나 외부 검색을 실행하지 않음.
- 기존 일정에서 비어 있던 숙박비도 저장 요금으로 보완 가능. 이미 확인한 생성 당일 가격은 보존.
